# GPAC wiki

This repository contains [GPAC's wiki](https://wiki.gpac.io), the entrypoint to [MP4Box](https://wiki.gpac.io/MP4Box) and [GPAC](https://wiki.gpac.io/Filters) documentation.


## Contributiing

Contributions are welcome and can be submitted through pull requests.

Some of the markdown files are autogenerated by GPAC and MP4Box, see: `scripts/genmd.sh`. These files must be edited by editing GPAC C source code and contributed to GPAC.


Make sure to keep the navigation structure in the `mkdocs.yml` configuration up to date when adding or removing new pages.


URLs are autogenerated from the markdown file names.


### llms.txt / llms-full.txt

The site also publishes [`llms.txt`](https://wiki.gpac.io/llms.txt) and `llms-full.txt`, a curated index and a full-content export intended for LLM tools to consume instead of crawling the rendered HTML. These are generated automatically by `mkdocs build`/`mkdocs serve` via the `llmstxt` plugin configured in `mkdocs.yml`.

The plugin's `sections:` list, however, is **not** auto-synced with `nav:` — it's a snapshot generated by `scripts/gen_llms_sections.py`. When you add, remove, or move pages in `nav:`, regenerate it and paste the result back into `mkdocs.yml`:
```bash
python3 scripts/gen_llms_sections.py
```
`glossary/` is intentionally excluded for now pending a content review.

A pre-commit hook catches the common case of forgetting this — it blocks a commit that touches `nav:` in `mkdocs.yml` without regenerating `sections:` to match. It lives in `.githooks/` (not `.git/hooks/`) so it's tracked and shared; enable it once per clone with:
```bash
git config core.hooksPath .githooks
```


## Development & build

This documentation uses the [**materials** theme](https://squidfunk.github.io/mkdocs-material/) for [**mkdocs**](https://www.mkdocs.org/).

**Intall all dependencies**:
```bash
python3 -m pip install mkdocs-material==9.5.44 mkdocs-llmstxt==0.5.0
```

**Local preview with hot reloading**:
```bash
mkdocs serve
```

**Release build**:

```
mkdocs build --clean -d ./site
```
